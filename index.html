01 · CASO DE ESTUDIO

Asignación presupuestaria entre unidades

Un modelo financiero académico para distribuir recursos entre cuatro áreas organizacionales interdependientes.

Contexto del problema

Una organización debe determinar una asignación presupuestaria coherente para cuatro unidades: Infraestructura, Desarrollo, Seguridad y Capacitación. Las necesidades de cada unidad no son independientes: existen costos compartidos, dependencias operativas y restricciones de planificación.

El modelo representa esas relaciones mediante un sistema lineal simétrico y definido positivo. Las variables desconocidas expresan asignaciones presupuestarias normalizadas, en miles de bolivianos (miles de Bs), dentro de un modelo académico simplificado.

Alcance: los coeficientes y montos son datos sintéticos de demostración. No representan estados financieros ni datos observados de una empresa real.

02 · FORMULACIÓN MATEMÁTICA

Representación del sistema financiero

El problema se expresa como un sistema de ecuaciones lineales.

A x = b
A

Matriz de interacción y ponderación financiera (4 × 4).

x

Vector de asignaciones presupuestarias desconocidas.

b

Vector de necesidades o requerimientos financieros.

Interpretación de los coeficientes

  • aᵢᵢ: ponderación propia de la unidad i; representa su peso presupuestario relativo.
  • aᵢⱼ: interacción o dependencia entre las unidades i y j.
  • bᵢ: requerimiento financiero asociado a la unidad i.
  • xᵢ: asignación calculada para la unidad i, expresada en miles de Bs.

La matriz se construye simétrica para representar interacciones recíprocas y definida positiva para garantizar una solución única y permitir la aplicación del método de gradientes conjugados.

Condiciones matemáticas

A = Aᵀ Simetría
xᵀ A x > 0, para todo x ≠ 0 Definición positiva
‖rₖ‖₂ / ‖b‖₂ < 10⁻⁶ Criterio de parada

La aplicación verifica la simetría y la definición positiva mediante factorización de Cholesky. También calcula los autovalores para documentar la condición de la matriz.

Ideal

Situación estable y equilibrada. La matriz está bien condicionada, por lo que se espera una convergencia rápida.

02
PERTURBACIÓN

Bajo estrés financiero

Se simula un aumento de costos y una redistribución de necesidades presupuestarias. Se analiza el nuevo punto de equilibrio.

03
PRUEBA NUMÉRICA

Mal condicionado

Se introducen escalas muy diferentes entre unidades, elevando κ(A). Jacobi busca equilibrar el escalamiento diagonal.

Nota metodológica: el escenario mal condicionado se construye como A = D R D, donde D contiene escalas distintas y R representa interacciones simétricas. El precondicionador de Jacobi utiliza la diagonal de A para reducir el efecto del escalamiento.

06 · FUNDAMENTO COMPUTACIONAL

¿Cómo funciona el GCP?

El precondicionamiento transforma el sistema para favorecer una convergencia más rápida.

01

Residuo inicial

r₀ = b − Ax₀

02

Precondicionamiento

Mzₖ = rₖ

03

Dirección conjugada

pₖ = zₖ + βₖpₖ₋₁

04

Actualización

xₖ₊₁ = xₖ + αₖpₖ

Precondicionador de Jacobi

Se utiliza M = diag(A), es decir, una matriz diagonal formada por los elementos de la diagonal principal de A. En cada iteración se resuelve Mzₖ = rₖ mediante divisiones componente a componente. Es un precondicionador sencillo y adecuado para demostrar la mejora cuando el mal condicionamiento se debe principalmente al escalamiento diagonal.

αₖ = (rₖᵀzₖ)/(pₖᵀApₖ)   ·   βₖ = (rₖ₊₁ᵀzₖ₊₁)/(rₖᵀzₖ)

La implementación usa el criterio ‖rₖ‖₂ / ‖b‖₂ < tolerancia, con tolerancia predeterminada 10⁻⁶. El método directo de Cholesky se utiliza como solución numérica de referencia.

08 · CONCLUSIONES Y REFERENCIAS

Interpretación final

El análisis conecta el comportamiento numérico con la interpretación financiera.

Conclusiones del experimento

  1. Un modelo financiero con variables interdependientes puede formularse como un sistema lineal simétrico y definido positivo, siempre que su construcción matemática lo garantice.
  2. La solución directa de Cholesky proporciona una referencia para cuantificar el error de los métodos iterativos.
  3. GC y GCP pueden llegar a la misma solución, pero el precondicionamiento puede reducir el número de iteraciones cuando mejora el condicionamiento efectivo del sistema.
  4. El número de condición ayuda a explicar la sensibilidad del sistema y las dificultades potenciales de convergencia.
  5. La modificación de los requerimientos financieros desplaza la solución; el efecto sobre el condicionamiento depende de si cambia A, b o ambos.
Interpretación responsable: los resultados representan un ejercicio numérico y no constituyen una recomendación de inversión ni una asignación presupuestaria real.
